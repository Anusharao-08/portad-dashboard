# Support and escalation

- **Dashboard bugs/features:** open an issue with reproducible steps, expected/actual behavior, browser/device details when relevant, and sanitized screenshots.
- **Core/API behavior:** link or file the issue in `IndianjobsTech/PortaD`; do not reimplement migration logic in the dashboard.
- **Security vulnerability or exposed secret:** do not open a public issue. Use GitHub's private vulnerability reporting if enabled and notify maintainers privately.
- **Usage/design questions:** use GitHub Discussions if enabled; otherwise open a clearly titled question issue.
- **Possible data loss or integrity issue:** stop the affected workflow, notify maintainers privately, preserve only sanitized diagnostics, and do not encourage repeated retries until state is understood.

Support is best-effort unless a separately published service-level commitment says otherwise. Never post tokens, credentials, customer exports or personal data in public channels.
